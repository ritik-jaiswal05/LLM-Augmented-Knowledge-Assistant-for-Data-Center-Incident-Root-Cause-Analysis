[SYNTHETIC] Latency spike from noisy neighbour VM
Category: latency
Symptoms: One VM shows slow disk and CPU steal time above 20% while its own load is low. Other VMs on the same host are busy.
Root cause: Resource contention from a noisy neighbour on the same hypervisor host.
Diagnostic steps: Check CPU steal and host utilisation; migrate VM to another host; apply resource limits to the noisy tenant.
