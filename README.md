# 🚀 RCA Assistant – Root Cause Analysis Tool

**An Intelligent Root Cause Analysis Assistant for Automated Incident Investigation**

RCA Assistant is a Python-based project designed to simplify incident investigation and Root Cause Analysis (RCA). It helps analyze incident-related information, identify possible root causes, and generate structured analysis results.

---

## 📌 About The Project

Root Cause Analysis (RCA) is an important process used to identify the underlying reasons behind system failures, errors, and incidents.

The RCA Assistant aims to make this process easier by organizing incident knowledge, processing incident data, and assisting in root cause identification.

This project demonstrates how Python can be used to build an intelligent assistant for incident analysis and troubleshooting.

## ✨ Key Features

* 🔍 **Incident Analysis:** Analyze incident-related information.
* 🧠 **Knowledge Base:** Maintain incident knowledge and reference data.
* ⚙️ **Automated RCA:** Assist in identifying potential root causes.
* 📊 **Evaluation Module:** Evaluate the analysis and results.
* 📁 **Data Management:** Organize incident datasets and results.
* 📝 **Structured Output:** Generate organized RCA results.

## ⚡ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Navigate to Project Folder

```bash
cd Rca-Assistant
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

**Mac/Linux**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
python app.py
```

> Note: Use the appropriate script and configuration based on your project setup.
